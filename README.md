# 特別ソフトウェア開発実践演習

本リポジトリは、**「特別ソフトウェア開発実践演習2026」講義で使用する教材・サンプルコード・演習課題等を公開するためのリポジトリ**です。

 - 受講者は、講義の進行にあわせて本リポジトリの内容を参照してください。
 - 講義進行に応じて、MainBranchを更新していきますので、講義日には適宜Pullを行なって下さい。
 - 授業日にDiscussionへ新しいスレッドを立てます。講義資料をそこに掲示するので、参照願います。

---

## 1. 講義概要

### 講義の目的

本講義では、RAGChatBotとその拡張を題材として、ソフトウェア開発の基礎とAIを活用に必要となる一連のプロセスを座学と演習を交えて学んでいきます。

### 到達目標

本講義の終了時点で、以下を身につけることを目標とします。

* ソフトウェア開発プロセスについて概観を理解する
* クラウド・CICD・メトリクス監視といったデプロイプロセスについて概観を理解する
* AIを利用した開発を進めることができる
* AI/LLMの基礎的な理論や活用について理解する
* 自身のアイデアを機能実装することができる

### 講義形式

* 講義＆ハンズオン
  * 講義前半では座学を中心に開発の基礎的な内容について紹介します。適宜簡単なHandsOnを展開します。
  * 講義後半ないし授業後の空き時間などで＋αなHandsOnを実施します。時間に余裕のある方はご参加ください。
* 調査課題・アンケート
  * 授業毎に簡単な調査課題とアンケートを展開します。(後述)
* 最終実装課題＆発表
  * 講義最後に、独自のアイデアで実装した機能やシステムについて発表して頂きます。(後述)

## 2. 受講にあたって

### 前提知識

特段の前提知識は必要ありません。お気軽にどうぞ。

### 使用する環境・ツール

本講義では、主に以下を使用します。

| 種別        | ツール／環境       | 用途           |
| --------- | ------------ | ------------ |
| ソースコード管理  | Git / GitHub | ソースコードの管理・講義資料の展開 |
| 開発環境      | Dockerが動くPC        |  ソースコードのローカル検証       |

### 聴講のみ

講義を受講せず、聴講のみの参加も歓迎します。シラバスを下記に記載してますので、気になる講義回のみピンポイントで参加頂いても構いません。
ただし演習や質問対応といったフォローアップの優先度が下がることはご承知おき下さい。

### 欠席の取り扱い

可能な限りMailにて連絡をください。やむを得ない理由、学会や社会貢献活動などで欠席される場合であれば、後述のアンケート課題を提出頂くことで、出席と同様の評価をします。

## 4. 評価

本講義の評価は下記二つの要素で実施しします。
 - アンケート課題(30点)
   - 毎回の講義で、簡単な調査課題 兼アンケートをGoogleFormで提示します。次回講義までに回答ください。
   - 授業で触れられなかった要素技術やキーワードについて調べて貰います。生成AIを使っても構いませんが、一読して頭の片隅に残るようにしましょう。
   - 一回の提出で 2点の評価点とします。
 - 個人開発課題 (70点)
   - 解説は講義中に行いますが、受講者各位の好きなアイデアで「講義で使用するシステムの機能拡張」や「独自システムを構築」して発表を行なって頂きます。
   - 難しく感じるかもしれませんが、成果物は完璧である必要はなく、どういった点が不足しているかなどを理解、認識できていれば特段の減点はしません。
   - Issueないし受講者のRepositryにおいて実装の相談やフォローアップをするので、無邪気に考えてみて下さい。
   - 最終課題の評価ポイント
     - コンセプト(10点)：アイデアや独自性、おもしろさ
     - 発表の体裁(10点)：発表が伝わりやすかったか
     - 開発の工夫(25点)：講義で学んだ開発手法を活かせたか
     - 実際の実装(25点)：動作する実装が作れたか
